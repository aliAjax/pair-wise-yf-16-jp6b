# hxyfront-62004 滑雪板调校维护

面向滑雪板调校店的装备维护工单系统，替代纸质台账。

## 功能

- **工单列表**：待维护 / 待交付 / 已完成状态筛选，顶部实时统计
- **工单表单**：雪板品牌、板长、板型、侧刃/底刃角、打蜡类型、客户偏好，一单全录
- **底板损伤标记**：在底板图上点选划痕 / 边刃伤落点；同一损伤点可追加多次修补，每次记录修补时间、修补位置/工艺与备注
- **完工拦截**：完工交付时校验——损伤点没有修补记录、修补记录未填修补位置，或最后一次修补时间晚于完工时间，均无法完工并逐条指出冲突
- **客户档案**：按客户归并工单，按最近维护时间排序；打开旧工单可查看当时记录的参数快照（只读）
- **本地持久化**：数据保存在浏览器 localStorage，换班后重新打开即可继续处理

## 技术栈

React + Vite + TypeScript

```bash
npm install
npm run dev
```
